The capture exercises actual UI and authenticated MCP tools in a disposable
sample project. Four application tests and three MCP checks pass on screen.
Narration is synthetic. No native-model generation or third-party CLI
conversation is simulated; the report identifies those coverage limits and a
pending diff acknowledgement issue found during recording.

The local production folder `.build/demo/exports/` also contains the separate
narration WAV and media verification artifacts. The MP4 files use H.264/AAC,
1920×1080 resolution, 30 fps and fast-start metadata.
