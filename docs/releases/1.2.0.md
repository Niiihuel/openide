OpenIDE 1.2.0 updates the editor foundation to Code OSS 1.136.1 with Electron 42.10.0 and Node.js 24.18.0 for builds. OpenIDE keeps its own product version; extension compatibility follows the Code OSS API version.

- Voice dictation now selects an audio format supported by the provider and model, with microphone testing, cancellation and a live, collapsible provider selector.
- The composer switches between microphone and send controls. Chat layout, full-width diff highlights, dock separators, notices, conversation titles and tab icons have been improved.
- Zen mode and edit animations cancel promptly, batch rendering work and preserve composer focus during browser automation.
- Settings search avoids rebuilding the full interface on every keystroke.
- Removing the active provider account selects a remaining saved account. Codex model discovery reads the authenticated account's catalog and can refresh without restarting the IDE, including newly available models such as GPT-6 Astra when the account exposes them.
- AppImage updates relaunch through the installed launcher, acknowledge a successful workbench startup and cancel in-flight downloads when updates are disabled.
- Update discovery opens a popover without stealing keyboard focus. Stable update feeds are published only after release assets are public and their signatures and hashes have been verified.

Automatic installation is supported for Linux x64 AppImage and Windows x64/ARM64 user installers. Linux ARM64 packages are available for manual installation. macOS binaries are not included in this release. Development builds do not receive application updates.
