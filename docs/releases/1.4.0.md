# OpenIDE 1.4.0

OpenIDE 1.4.0 introduces the Agents Window, a complete conversation workspace for coordinating chats, subagents, changes, terminals, sources and browser work without losing the project context. It also expands native agent tooling, project intelligence and visual consistency across the IDE. The editor remains based on Code OSS 1.136.1.

## A dedicated workspace for agents

The Agents Window keeps conversations, their individual changes and related work together. Each chat retains its own review state, terminals, sources and minimized views. Sidebars can be opened, closed and resized independently, while editors and browser views move between the main IDE and the Agents Window without duplicating their state.

Conversation navigation is denser and easier to scan. Project and session previews expose useful context on hover, subagent runs use activity-specific icons, and active, completed and historical work stays synchronized between the chat, the sessions tree and the Environment panel.

## Clearer chat activity and review

Tool activity now uses compact, collapsible rows with consistent progress, errors and completed-action summaries. Repeated edit placeholders and duplicate browser cards are removed. File edits remain scoped to their originating conversation and can be reviewed, kept or undone from the chat or the Changes editor.

The composer, attachments, background terminals, model picker and approval controls share one visual system. Hover, focus, spacing, color and motion follow the same tokens across dark and light themes, including reduced-motion behavior.

## Browser and Playwright feedback

Browser tabs recover cleanly when a local preview disappears instead of leaving a blank white editor. Links can open in the integrated browser or the system browser, with GitHub links receiving their native icon and context menu.

Playwright activity now appears in both the chat and the browser tab. Pointer movement, clicks, typing, scrolling and navigation are visualized while automation runs, and the indicator follows the real execution lifetime, including deferred work and errors.

## Goals, Canvas and project intelligence

Goals can persist, resume and report pending work through the native agent host. Canvas and design tools open as first-class editors with export support. The native codebase engine adds graph, syntax and query layers so agents can inspect project structure without repeatedly loading the whole repository into the renderer.

Memory, run journals and CLI connections have stronger ownership and recovery boundaries. Background extraction is isolated from foreground turns, and session state survives window changes without crossing workspace or conversation boundaries.

## Validation and platform notes

The release adds native runtime coverage for Agents Window layout, docking, sessions, changes, terminals, browser behavior, Playwright feedback, goals, Canvas and codebase queries. Linux x64/arm64 and Windows x64/arm64 packages are built by the release workflow. Automatic update feeds cover Linux x64 AppImage and Windows user installers; macOS packaging remains disabled.
