# OpenIDE 1.5.0

OpenIDE 1.5.0 makes agent work easier to follow, gives the browser agent a native action overlay, and refines the Agents Window and provider setup.

## Agent conversations

- Reasoning, tool calls, attachments, compaction and delegated subagents now present their progress in a clearer, more consistent stream. Long conversations retain their history without a fixed 200-cycle stop.
- Sessions have a simpler navigation layout, and the conversation workspace keeps background terminals with the other open views instead of covering the composer.
- A new conversation opens with a quiet centered prompt. Skill suggestions use a distinct book icon and show complete names; command argument hints no longer show angle brackets.
- When the agent needs an answer, approval, account choice or mode decision, OpenIDE shows a notification and plays the Workbench action-required sound. The notification opens the relevant conversation and clears when the request is resolved.
- Changed files show their diff indicators, can be sent to chat as file context, and can be accepted together from the review view.

## Browser agent

- Playwright actions pass through a runtime-independent event contract and session model before reaching the UI.
- The existing browser viewport now shows a native animated cursor, target highlight, click feedback, navigation state and compact activity HUD. Coordinate conversion keeps the overlay aligned through resize and scaling.
- Browser sessions connect to tool calls, while the renderer remains independent of Playwright and respects reduced-motion settings.
- Optional console and network diagnostics in the native preview capture bounded, redacted evidence for debugging without flooding the conversation.
- Local URLs activated in the terminal open the integrated browser by default. The hover explains both routes and offers an external-browser action; Shift plus the terminal link modifier opens externally.

## Agents Window and settings

- An expanded native editor is separate from the right-side workspace dock. Closing the modal returns to the dock without promoting its previous view to full screen.
- Project switching and agent-window views have clearer ownership, navigation and presentation.
- Provider discovery, manual setup and API-key flows have a revised layout; Skills, Voice, Subagents and Project Map settings have been refined for consistency and readability.

Automatic update feeds cover the Linux x64 AppImage and Windows x64/arm64 user installers. Linux arm64 packages remain available for direct download.
