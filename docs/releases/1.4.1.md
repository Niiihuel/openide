# OpenIDE 1.4.1

OpenIDE 1.4.1 delivers the complete 1.4 feature set with a portable release pipeline for Linux x64/arm64 and Windows x64/arm64. It keeps the Agents Window, per-conversation changes, compact subagent activity, browser and Playwright feedback, persistent goals and native project intelligence introduced in 1.4.0.

## Release reliability

The native codebase verification now discovers its fixtures with Node.js instead of depending on a runner-installed search utility. The packaged desktop bootstrap also loads WebSocket support only after Electron installs its ASAR resolution hooks. These changes make the same verified source build consistently on every release runner.

## Main improvements in 1.4

- A dedicated Agents Window keeps chats, their individual changes, terminals, sources and minimized views together.
- Conversation and subagent state stays synchronized across the chat, sessions tree and Environment panel.
- Tool activity uses compact, collapsible rows and removes duplicate edit and browser entries.
- Integrated browser views recover when a local preview stops, and links can open internally or in the system browser.
- Playwright actions show pointer, click, typing, scrolling and navigation feedback with an active tab indicator.
- Goals, Canvas and native codebase graph, syntax and query layers remain connected to their originating conversation.

Automatic update feeds cover the Linux x64 AppImage and Windows user installers. Linux arm64 packages remain available for direct download.
