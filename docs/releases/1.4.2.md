# OpenIDE 1.4.2

OpenIDE 1.4.2 improves the reliability and clarity of long agent sessions while tightening the visual language of the Agents Window. Streaming activity, plans, subagents, browser actions, terminals and project context now stay visible and consistent throughout a run.

## Agent sessions and recovery

- Run-journal checkpoints preserve more in-flight state and recover cleanly when the Agent Host stops responding.
- Streaming tool activity remains incremental instead of appearing only with the final response.
- Repeated tool calls and subagent waits are grouped more clearly, while plan progress continues updating in the background.
- Memory checkpoint errors explain the invalid reference without discarding provider or credential state.

## Chat and workspace experience

- Slash commands and skills use a compact command palette with command-specific icons, stable focus and separated hover rows.
- Terminal output streams into compact expandable cards without an inline terminal input.
- Subagents use their delegated prompt as the title, expose individual work, and render stable avatars.
- Files and URLs in chat open through the appropriate editor or browser destination.
- Browser activity displays the target URL and remains docked when its content or viewport changes.

## Interface polish and performance

- Environment, sticky composer and main composer now share the same surface, border and spacing hierarchy.
- The Agents Window distinguishes an empty workspace from a selected project and offers an explicit project picker.
- Title-bar menus open reliably and the auxiliary window no longer duplicates the application icon.
- Loading skeletons use lightweight opacity animation and avoid unnecessary layout work during plans and editor loading.
- Usage status keeps transient progress inside its popover and shows per-request elapsed time in the chat status.

Automatic update feeds cover the Linux x64 AppImage and Windows x64/arm64 user installers. Linux arm64 packages remain available for direct download.
